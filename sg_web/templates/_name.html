{# Cut a filename in the middle: firstpart…endpart Generated names share a long head and differ in the tail, so cutting the end hides the only part that identifies the file, extension included. Two spans, no script. The head takes the ellipsis and all the squeeze; the tail never shrinks. textContent is the whole name. #} {% macro middle(text, tail=16) %} {%- set text = text | string -%} {%- if text | length <= tail + 8 -%} {{ text }} {%- else -%} {{ text[:-tail] }}{{ text[-tail:] }} {%- endif -%} {% endmacro %}
