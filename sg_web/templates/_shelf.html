This owns the card. #} {% macro seen(first, last) %} {# A span of days. The browser spells the epochs (frontend/src/spelling.ts). #} {%- if last is not none %} {{ first }}{% if last != first %} – {{ last }}{% endif %} {%- endif %} {% endmacro %} {% macro cover(shots, empty="empty") %} {# One shot fills the frame, several tile it. `empty` is the word to show when there is no picture to take — a rule-defined collection or an unscanned folder, neither of which gets a grey square. #} {%- if shots %} {%- for shot in shots[:4] %}{% endfor -%} {%- else %} {{ empty }} {%- endif %} {% endmacro %} {% macro card(href, name, meta, shots=None, empty="empty", attrs={}, first=None, last=None, state=None) %} {# `attrs` carries the page's own hooks: data-album, data-folder, data-place, data-artifact.
