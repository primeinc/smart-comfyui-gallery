How to use

  1. Click any image above (or paste a file id) — the comparison runs immediately.
  2. Overlay stacks every lane's boxes on one image; use each lane's checkbox and opacity slider to isolate it.
  3. Side by side shows one image per lane with its model identity and timing.
  4. Dashed boxes are disagreements — faces one detector finds and the other misses.
